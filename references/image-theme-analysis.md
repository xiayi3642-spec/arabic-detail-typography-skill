# 套图明暗与配色

用户上传产品套图、拼接联系表或多张详情页底图时，先为文字层建立与图片一致的主题，再排版。目标不是机械吸色，而是保证头部文字清晰并让整套图的颜色系统统一。

## 分析区域

- 文字通常位于画面头部，优先分析每张图片顶部约 1/3 的亮度、明暗波动和主色；不要只用整张图平均亮度。
- 单张拼接联系表无法可靠代表每个格子的局部背景时，先给出全套统一主题；若用户需要逐格精确适配，应让每个格子对应的原图分别进入分析。
- 文字透明层预期等宽叠到每格时，按实际放置区域判断，不要被底部产品、火焰或地面颜色带偏。

## 深浅正文

- 从套图可靠出现的最深色与最浅色中选正文候选色，分别计算它们与头部背景的对比度；选择更清晰的一端，不默认黑或白。
- 多张图结论一致时，全套统一深色或浅色正文。只有头部背景明显混合时才逐图适配深浅，并保持强调色统一。
- 禁止使用文字阴影、外发光或阴影式描边补救对比度。对比不足时，必须改换深/浅文字、调整颜色或更换放置区域。
- “明/亮色背景”模式表示在白色或浅色底图上预览，必须使用深色正文；“暗/深色背景”模式才使用浅色正文。模式名指背景，不是文字颜色。
- 最终缩略预览仍应清晰；不要以“颜色来自图片”为理由接受低对比度文字。

## 两种强调色

- 关键词使用强调色 A，小装饰、交替 Icon 或次级标记使用强调色 B。
- 两种色都应来自整套图的稳定色群，并彼此有足够差异；避免从单个噪点或高光中取色。
- 强调色还必须与头部背景、正文色有区分。若图片主要是单色，可由主强调色与正文色适度混合生成第二色，但要保留整套一致性。
- 正文色、弱化色、强调色 A、强调色 B 是同套页面的共享主题；随机切换模板不得重置这些颜色。
- 切换到暗色背景时，可换用浅色正文和弱化色，但不得用通用浅金色覆盖套图已提取的强调色；只要对比度足够，关键词和装饰应继续使用原套图橙色等品牌色。

## 维护页

在 AI 维护页使用“上传套图”可一次选择多张图片。维护页会分析顶部区域、显示正文/关键词/装饰色三个色样，并把主题应用到所有排版卡。上传新的套图会覆盖当前主题；不会改写文案。已分析的配色必须在页面刷新、重新打开和随机切版后继保留；“复制 2× 透明图”必须快照当前卡片的实际计算配色和无阴影状态，不得回落到模板默认色。验收截图应以当前透明棋盘格卡片为主体，不得用默认配色页面代替。
